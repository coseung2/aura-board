# 학생 학습 피드 플랫폼 계약

## 목표와 범위

Aura Board에 홈과 분리된 학생용 `피드` 화면을 추가한다. 피드는 초등학교 교육과정과 연결된 짧은 카드뉴스 또는 교사가 승인한 YouTube 자료를 제공한다. 웹과 Expo 모바일에서 같은 콘텐츠·읽음 상태·저장 상태를 사용하되, 화면 구성과 탐색 방식은 각 플랫폼 관례에 맞춘다.

초기 납품 범위는 검수 완료된 콘텐츠 정확히 100개다. 단순 제목·요약 생성이나 임시 시드 100개는 완료로 보지 않는다. 각 항목은 교육과정 근거, 사실 출처, 연령 적합성, 이미지 권리, 발행 상태를 모두 가져야 한다.

## 교육과정 출처

- 인스타그램 Threads에서 공유되었던 초등교육과정 MCP는 게시물과 서버를 다시 특정하지 못했다. 확인되지 않은 MCP를 임의로 설치하거나 신뢰하지 않는다.
- 현재 기준 원본은 국가교육과정정보센터(NCIC)의 2022 개정 교육과정이다: <https://www.ncic.re.kr/>.
- MCP는 `CurriculumSourceAdapter` 뒤에 둔다. 나중에 원본 MCP가 확인되면 동일한 정규화 계약과 출처 검증을 통과한 뒤 NCIC 어댑터와 병행하거나 교체한다.
- 생성 모델의 기억만으로 학년, 과목, 성취기준 코드 또는 성취기준 문구를 만들지 않는다. 원본에서 조회되지 않은 매핑은 `unverified`로 두고 발행하지 않는다.
- 교과서 PDF나 기존 `pace_curriculum_lesson_memory`를 사용할 때는 출판사·저자·학년·학기 범위를 보존하고, 원문 전체를 피드에 복제하지 않는다.

## 정보 구조

### 학생

- 주요 탐색: `홈`과 동급인 `피드` 목적지를 제공한다.
- 피드 상단: 추천, 사회, 과학, 국어, 수학, 생활·안전 등 승인된 분류를 가로 필터로 제공한다.
- 항목: 표지, 제목, 한 문장 핵심, 학년·과목, 예상 읽기 시간, 콘텐츠 형식, 출처 표시를 일관된 순서로 보여준다.
- 카드뉴스 상세: 4~8장의 짧은 페이지, 핵심 용어, 생각 질문 1개, 교육과정 근거, 사실 출처를 제공한다.
- YouTube 상세: 앱 내부 자동재생 금지, 명확한 외부 이동, 영상 길이·채널·게시일·검수일·왜 추천하는지 표시, 가능하면 자막 또는 대체 요약을 제공한다.
- 개인 상태: 읽음, 나중에 보기, 최근 본 항목을 본인만 조회한다. 공개 좋아요 수나 학생 간 순위는 초기 범위에서 제외한다.

### 교사·관리자

- 초안, 검수 대기, 발행 예약, 발행, 보관 상태를 관리한다.
- 교육과정 매핑과 사실 출처가 누락된 콘텐츠는 발행할 수 없다.
- YouTube 영상이 삭제·비공개·연령 제한·임베드 금지로 바뀌었는지 재검수할 수 있다.
- 학생에게 노출되는 내용과 내부 검수 메모를 분리한다.

## 콘텐츠 데이터 계약

각 콘텐츠는 최소한 다음 필드를 가진다.

```ts
type StudyFeedItem = {
  id: string;
  stableKey: string;
  kind: "card_news" | "youtube";
  status: "draft" | "review" | "scheduled" | "published" | "archived";
  title: string;
  dek: string;
  subject: string;
  gradeBands: Array<{ min: number; max: number }>;
  curriculum: Array<{
    revision: "2022";
    subject: string;
    grade: number;
    semester?: number;
    domain?: string;
    achievementCode: string;
    achievementText: string;
    sourceUrl: string;
    sourceDigest: string;
    verifiedAt: string;
  }>;
  sources: Array<{
    label: string;
    url: string;
    publisher: string;
    publishedAt?: string;
    checkedAt: string;
  }>;
  pages?: Array<{
    order: number;
    heading: string;
    body: string;
    visualAlt: string;
    assetId?: string;
  }>;
  youtube?: {
    videoId: string;
    canonicalUrl: string;
    channelTitle: string;
    durationSeconds: number;
    publishedAt: string;
    checkedAt: string;
    captionsAvailable: boolean;
  };
  coverAssetId: string;
  estimatedSeconds: number;
  ageReview: "pass" | "needs_review" | "fail";
  factReview: "pass" | "needs_review" | "fail";
  rightsReview: "pass" | "needs_review" | "fail";
  createdAt: string;
  updatedAt: string;
};
```

읽음·저장은 학생 식별자와 콘텐츠 식별자의 서버 권위 레코드로 관리한다. 재시도해도 읽음 횟수가 중복 증가하지 않도록 고유 키와 멱등 쓰기를 사용한다. 다른 학생의 개인 피드 활동은 조회할 수 없어야 한다.

## 초기 콘텐츠 100개 구성

초기 세트는 특정 학년이나 과목에 몰리지 않도록 다음 목표를 사용한다.

| 영역 | 수량 | 주제 예시 |
|---|---:|---|
| 사회 | 20 | 지역, 지도, 민주주의, 경제생활, 문화유산, 세계 시민 |
| 과학 | 20 | 생명, 물질, 힘과 에너지, 지구와 우주, 환경, 탐구 안전 |
| 국어 | 15 | 읽기 전략, 매체 문해력, 말하기·듣기, 어휘, 문학 감상 |
| 수학 | 15 | 수와 연산, 도형, 측정, 규칙성, 자료와 가능성 |
| 도덕·생활·안전 | 10 | 관계, 디지털 시민성, 재난·교통·생활 안전 |
| 예술·체육·실과 | 10 | 감상, 표현, 건강, 놀이, 생활 기술, 지속가능성 |
| 융합·시사 | 10 | 기후, AI, 우주, 생태, 공동체를 두 과목 이상과 연결 |

추가 품질 조건:

- 1~2학년, 3~4학년, 5~6학년 묶음이 각각 최소 25개를 가져야 한다.
- 동일한 성취기준 하나에 5개를 초과해 몰리지 않는다.
- 카드뉴스가 최소 80개이며, YouTube 링크는 최대 20개다.
- 같은 사실, 같은 영상, 제목만 바꾼 중복은 허용하지 않는다.
- 시사 항목은 발행 직전 날짜와 사실을 다시 확인하고 `checkedAt`을 기록한다.
- 카드뉴스 본문은 한 페이지당 핵심 메시지 하나, 짧은 문장, 이해를 돕는 시각 자료 하나를 원칙으로 한다.

## 시각·상호작용 원칙

- 일반 보드 카드나 휘황찬란한 게임 UI를 재사용하지 않는다. 학습 콘텐츠가 주인공인 차분하고 명료한 편집형 피드를 사용한다.
- 중첩 카드, 과도한 그라데이션, 불필요한 배지와 설명 문구를 피한다.
- 모바일은 한 열 읽기 흐름과 하단 주요 탐색, 갤럭시 탭은 목록·상세 2열 전환을 지원한다. 웹은 주소 이동, 새로고침, 뒤로 가기와 필터 상태를 보존한다.
- 터치 영역은 최소 44×44, 웹 키보드 탐색과 명확한 포커스, 동적 글자 크기, 화면 읽기 순서, 이미지 대체 텍스트, 모션 감소를 지원한다.
- 로딩, 비어 있음, 결과 없음, 오프라인, 부분 실패, 삭제된 영상, 접근 제한, 재시도 상태를 각각 구분한다.

## 안전·저작권·개인정보

- 초등학생에게 부적절한 폭력, 선정성, 혐오, 공포, 상업 유도, 개인정보 노출을 자동·수동으로 검사한다.
- 이미지 생성물은 생성 이력과 프롬프트 버전을 기록한다. 제3자 이미지나 영상 썸네일은 허용 범위와 출처를 보존한다.
- YouTube는 검수된 정확한 영상 ID만 허용하고 관련 영상 피드나 댓글을 학습 콘텐츠로 간주하지 않는다.
- 학생 행동 데이터로 민감한 능력·성향을 추론하거나 광고 프로필을 만들지 않는다.

## 구현 순서

1. 게임 플랫폼 작업을 완료하고 92점 및 모든 필수 게이트를 통과한다.
2. 교육과정 어댑터, 콘텐츠 스키마, 발행 상태, 읽음·저장 계약을 먼저 확정한다.
3. 웹·모바일 피드 탐색과 상세 화면, 교사 검수 화면을 구현한다.
4. 콘텐츠 생성 파이프라인으로 100개 초안을 만들고 출처·성취기준·안전·권리를 검수한다.
5. 검수 통과 항목만 발행 시드에 포함하고 웹·갤럭시 탭에서 시각·기능 검증한다.

## 완료 기준과 채점표

총점 100점, 합격선 92점이다. 아래 필수 게이트 하나라도 실패하면 점수와 무관하게 불합격이다.

| 영역 | 배점 | 합격 증거 |
|---|---:|---|
| 교육과정 정확성·출처 추적 | 25 | 100개 전부 유효한 성취기준과 원본 URL·digest·검수일 보유 |
| 콘텐츠 품질·연령 적합성 | 20 | 중복 없음, 사실·연령·권리 검수 통과, 카드뉴스 가독성 표본 검수 |
| 피드 제품 경험 | 15 | 탐색·필터·상세·저장·읽음과 완전한 상태 설계 |
| 웹·모바일·태블릿 완성도 | 15 | 반응형 웹, Expo 모바일, 갤럭시 탭 실기기 증거 |
| 데이터 무결성·개인정보 | 15 | 서버 권위, 멱등성, 권한 격리, migration/index/API 테스트 |
| 접근성·검증·유지보수성 | 10 | 키보드·스크린리더·동적 글자·테스트·build·Android export |

필수 게이트:

- 검수 통과 후 발행된 콘텐츠가 정확히 100개다.
- 모든 항목에 교육과정 매핑과 사실 출처가 있으며 생성 모델만을 출처로 쓰지 않는다.
- 웹과 모바일에서 피드, 상세, 읽음, 저장이 실제 계정으로 동작한다.
- 다른 학생의 개인 활동을 조회하거나 임의로 수정할 수 없다.
- 링크·영상 장애가 전체 피드를 깨뜨리지 않고 복구 상태를 제공한다.
- 대상 테스트, 타입 검사, production build, Expo Android export, 갤럭시 탭 실기기 검증을 통과한다.
- production 데이터 적용, 비밀정보 변경, commit, push는 별도 사용자 승인 없이는 수행하지 않는다.

92점 미만이거나 필수 게이트가 실패하면 구체적인 결함을 수정한 뒤 같은 검증표로 다시 채점한다.
