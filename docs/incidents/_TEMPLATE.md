# YYYY-MM-DD — 간단-슬러그

| 항목 | 값 |
|---|---|
| severity | low / medium / high |
| 발생 | 언제, 어떻게 감지됐는지 |
| 해결 | 복구/수정 완료 시각 |
| 소요 | 진단·수정·배포·검증 총 소요 |

## 증상

사용자/모니터링이 본 것. 에러 문구, HTTP 상태, 화면, 로그 한 줄 등.

## 근본 원인

확정된 사실 기준(로그·커밋·요청/응답·설정 값). 추정은 "추정"이라고 명시.

## 수정

- 커밋 해시, 배포 run ID, 서버 env/설정 변경, 백업 파일 경로 등.
- 검증 방법과 결과(재현 명령, 새로고침/헬스 체크 등).

## 영향

영향받은 기능/사용자 범위. 데이터 손실·보안 영향 여부 명시.

## 재발 방지

체크리스트 항목, 코드 가드, 검증 절차 등 구체적 조치.

## 상세

필요 시 관련 링크/문서/산출물.
