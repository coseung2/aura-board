# 자리배정 모둠 표기와 홀수 인원 카드 높이

- 일시: 2026-09-08 22:25–22:31 KST (Asia/Seoul).
- 증상·영향: 모둠 설정이 분단으로 표시되고, 4자리 중 3명인 모둠의 2행 1열 카드가 다른 카드보다 높아졌다. 배정 데이터 손상은 확인되지 않았다.
- 확인 원인: `.seating-slot` 최소 높이 74px와 `.seating-desk` 최소 높이 54px의 차이로 CSS Grid가 빈자리 옆 학생 카드도 74px로 늘렸다. 모둠 설정·기본 이름·안내·저장 목록에는 분단 문자열이 남아 있었다.
- 대응: 빈자리 최소 높이를 학생 카드와 동일한 54px로 수정했다. 자리배정 UI 용어를 모둠으로 통일했다. 기존 숫자형 기본 이름만 편집기에서 정규화하고 사용자 지정 이름과 서버 데이터는 자동 변경하지 않는다.
- 검증: 실제 컴포넌트를 가상 학생으로 렌더링한 Chromium fixture에서 1440/768/390px 너비를 검사했다. 이전 CSS 주입 시 3번째 카드 74px 현상 재현, 수정 후 3명·4명 모둠의 모든 자리 높이 54px 확인. `output/playwright/seating-{1440,768,390}.png`에 증거 저장.
- 검사: 관련 Vitest 4파일 46개 통과, `npx tsc --noEmit` 및 `npm run check:lines` 통과. `npm run check:css-shards`는 HEAD와 CSS가 동일해야 하는 검사라 의도한 74→54 변경을 감지하여 실패했다. 해당 검사를 우회하거나 기준을 바꾸지 않았다.
- 범위·후속: 현재 로컬 코드에만 반영. 실제 로그인된 학급의 저장/재조회와 운영 배포는 이번 시각 수정 검증에 포함하지 않았다. 개발 서버는 사용자 테스트를 방해하지 않도록 유지했다.
