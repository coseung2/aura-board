# 노래 맞히기 문제 준비 잠금 안내 누락

- 일시: 2026-09-14 KST
- 증상: 교사 화면에서 클래식, 하이라이트, 20문제를 선택하고 준비하기를 누르면 `노래를 준비하지 못했어요.`만 표시됐다.
- 영향: 이전 노래 맞히기 게임이 진행 중인 학급에서는 새 문제 구성을 저장할 수 없었고, 교사는 해결 방법을 알 수 없었다.
- 확인 증거: 운영 API는 `POST /api/song-guess/boards/{boardId}/catalog`에 409를 반환했다. 해당 보드에는 2026-09-08 생성 후 `current=true`, `phase=reveal`로 남은 세션이 있었다. 클래식 하이라이트 20곡의 DB 행과 private storage 객체는 모두 존재했고 크기가 일치했다.
- 원인: 서버는 진행 중 세션이 있으면 의도대로 `song_guess_setup_locked`를 반환하지만, 곡 선택 UI가 모든 준비 오류를 동일한 일반 문구로 변환했다.
- 대응: 잠금 오류를 별도로 안내하고, 기존 게임을 종료할 수 있도록 방 목록으로 돌아가는 동작을 추가했다.
- 복구 검증: 관련 컴포넌트 회귀 테스트, 타입 검사, 운영 배포 후 기존 게임 종료와 클래식 20문제 준비·플레이 흐름을 확인한다.
- 예방: 상태 충돌 응답은 일반 네트워크 오류로 숨기지 않고 사용자가 해소할 수 있는 다음 동작과 함께 표시한다.
